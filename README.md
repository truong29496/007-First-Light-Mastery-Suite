## 🧭 Design Philosophy

Most utility suites are built like a toolbox — a pile of unrelated instruments you must learn individually. The Shadow Protocol Atelier is built like a **cockpit**: instruments are placed where your attention naturally falls, grouped by intent, and labeled with language that respects your intelligence.

Three principles guide every design decision:

1. **Reversibility** — Nothing is permanent. Every change can be undone with a single toggle.
2. **Transparency** — The tool shows you exactly what it's modifying and why.
3. **Restraint** — Features that would break narrative integrity are deliberately excluded or gated behind explicit opt-in.

## 🚀 Getting Started Pathway

Because the Atelier is distributed as a self-contained package, setup is intentionally minimal. The following steps assume you have the base game installed and running on a supported Windows build (10 or 11, 64-bit).

1. **Extract the package** to a dedicated folder outside your game directory — keeping it separate avoids conflicts during game updates.
2. **Launch the Atelier executable** before or after starting the game; the dashboard auto-detects an active session.
3. **Wait for the handshake** — a short status bar at the top confirms the connection to the running process.
4. **Browse the module tabs** and enable only what you need. Default state is "all off" for maximum safety.
5. **Adjust hotkeys** if the defaults overlap with your in-game bindings.
6. **Save your profile** so future sessions restore your exact configuration.

No command line required. No dependency chains. No obscure runtimes.

## 🛠️ Troubleshooting Essentials

- **Dashboard won't detect the game:** Ensure the game is running in windowed or borderless mode for the initial handshake.
- **Hotkeys not responding:** Check for conflicts with other overlay software.
- **FPS module shows no effect:** Verify that in-game V-Sync is disabled, as it can mask frame pacing improvements.
- **Language not applying:** Restart the dashboard once after selecting a new locale for the first time.
